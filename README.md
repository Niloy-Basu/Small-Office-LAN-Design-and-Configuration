

# Small Office LAN Design and Configuration

## Project Overview
This project demonstrates the design and configuration of a small office Local Area Network (LAN) using Cisco Packet Tracer.

## Objectives
- Build a small office LAN.
- Configure a Cisco router and switch.
- Assign static IPv4 addresses.
- Configure a default gateway.
- Establish communication between computers.
- Test network connectivity.

## Network Devices
- 1 Cisco 2911 Router
- 1 Cisco 2960 Switch
- 5 Desktop PCs
- 1 Network Printer

## Technologies and Concepts
- LAN
- Ethernet
- IPv4 Addressing
- Subnetting
- MAC Address Learning
- Default Gateway
- Ping and ARP

## Testing
Connectivity was tested using:
- ping
- ipconfig
- arp -a
- show ip interface brief


## Expected Result
All computers and the network printer should communicate successfully within the LAN.

## Tools
Cisco Packet Tracer
